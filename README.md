# Drag-droppable

Lightweight, data-driven, framework-independent drag-and-drop system with touch support and reactive stores.

## Tests

Run `npm test` for the regression suite, or `npm run test:watch` to rerun it
after edits. Tests use Node's built-in runner, with no additional dependency.
See [tests/README.md](tests/README.md) for an introduction and the limits of
the simulated DOM. Tests are excluded from the npm package by `files: ["src"]`.
